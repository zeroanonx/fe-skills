# 报告、HTML 与交接

生成同轮次 `migration.md` 和 `migration.html`，用唯一 run-id 防止覆盖历史。方案报告显示「未执行迁移」，执行报告显示真实进展与结论；不要将模板示例当验收成果。

内容包括：当前模式/结论、六阶段状态与退出检查、完整迁移任务清单、旧新版本、目标与边界、业务地图、工程映射、已确认规则及待确认项、规格链接、批次实现/验证状态、实际场景与证据、遗留风险及下一步。六阶段与完整迁移清单必须保留，简单模块可简写细项但不能合并阶段；代码详情链接实际文件，不复制整套规格。外链不可读时保留缺口，不把链接存在算读过。

HTML 使用 [模板](../templates/migration.html) 的语义结构，导航、表格、状态与证据链接可访问，窄屏表格可滚动，打印可阅读。动态文本进行 HTML 转义；默认静态、无外部脚本，不放凭证或真实个人数据。将占位符替换为实际内容，不适用细项写明原因，六阶段及完整任务清单不删除；HTML 与 MD 的规则、状态和缺口一致。

主动打开本次生成的 HTML，用环境可用浏览器/文件预览检查渲染、导航、链接和窄屏布局，不能只读取源码声称可视验收。打开或渲染受限时提供绝对文件链接并说明真实限制。报告内本地证据使用可解析的相对链接，交付聊天用绝对路径。

## 长任务续接

需要接手时生成 `handoff.md`：当前目标/模式/范围、当前阶段与六阶段门禁记录、完整任务清单、两端版本与原有改动、本次变更、已确认决策/否决原因、有效证据、进行中批次、失败/受阻/未知、下一项独立工作、必须取得的决定。恢复时核对当前仓库与快照差异，沿用有效决定；新证据出现才重新讨论已排除方案。

## 度量按需

用户要求复盘或提效分析时，固定提交、目录与统计口径。文件/行数/请求分支减少只说明结构变化；不能直接推导性能、质量或工时收益。实际投入互斥计时，等待单列，不从 Git 间隔估算。验证覆盖按有证据通过场景/全部计划适用场景计算，失败、受阻、未执行仍在分母；百分比必须同口径且分母非零。

交付说明实际改变的用户行为、代码位置、验证终态、缺口与风险。构建、上传、排队、部署和端到端验收分别表达；未发布就是未发布，不因代码完成而升级结论。
