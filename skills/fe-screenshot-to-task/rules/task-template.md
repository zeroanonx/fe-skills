# 任务输出模板

> 步骤 3 准备、步骤 4 落盘时严格遵循。流程见 [SKILL.md](../SKILL.md)。

## 文档头部

```markdown
# Tasks: {任务名称}（前端）

> 来源：{N} 张截图
> 业务线：{业务线名称}
> 端：{小程序 / H5 / 管理后台}
> 文件：fe-spec/tasks/{任务名称}/docs.md
> 截图目录：fe-spec/tasks/{任务名称}/screenshot/

## 截图索引

| 序号 | 文件                                  | 说明      |
| ---- | ------------------------------------- | --------- |
| 01   | [01-列表页](screenshot/01-列表页.png) | 列表页 UI |
```

截图链接相对于 `docs.md`，路径为 `screenshot/{文件名}`。

## 章节顺序（固定）

```markdown
## 0. 整体任务预览 ← 必填，尽可能详细

## 1. 路由与菜单 ← 须来自用户确认

## 2. 常量与枚举

## 3. 页面 — {PageName}

## 4. 组件 — {ComponentName}

## 5. 交互与状态流转

## 6. 校验与错误处理

## 7. 权限

## 8. 范围外

## 9. 待补充项 ← 必填，最后一章
```

**禁止章节**：API 与类型、验证清单、部署联调。

## §0 整体任务预览

读者无需翻截图即可理解需求。须包含：

````markdown
## 0. 整体任务预览

### 业务线

{名称} — {一句话定位}

### 做什么

{背景 / 目标 / 预期结果}

### 怎么做

{页面数、交互模式、技术要点、新建 or 改造}

### 页面全景

| 页面/组件 | 类型 | 路由/挂载 | 职责 | 关键元素 |
| --------- | ---- | --------- | ---- | -------- |

### 字段与展示

| 页面/组件 | 字段/列名 | 类型 | 说明 | 必填 | 来源 |

### 核心用户路径

```text
{入口} → {页面A} → 点击「{按钮}」→ {结果} → … → {终点}
```
````

| --- | -------- | -------- | ---- | ---- | --------- |

| ---- | -------- | -------- | ---------- |

### 业务规则摘要

- {菜单权限 / 操作权限}

- {无则写「无」}

## §1 路由与菜单

**须先 AskQuestion 确认**，再写入：

**新建路由：**

```markdown
- [ ] 1.1 **新建路由** `path: '/...'`，`name: '...'`
  - 菜单：{一级} → {二级}
  - 用户确认：{用户原话}
  - 来源：[01-xxx](screenshot/01-xxx.png)
- [ ] 1.2 在 `src/router/modules/xxx.ts` 追加配置（按项目实际文件）
````

**改造已有：**

```markdown
- [ ] 1.1 **不新建路由**，改造 `path: '/...'`（`name: '...'`）
  - 页面文件：`src/views/.../index.vue`
  - 用户确认：{用户原话}
```

## 单条任务格式

```markdown
- [ ] {章节号}.{序号} {可执行描述}
  - 来源：[01-列表页](screenshot/01-列表页.png)
```

含代码时加 **参照** + JSDoc 要求，见 [coding-conventions.md](coding-conventions.md)。

## 章节要点

| 章节      | 内容                            |
| --------- | ------------------------------- |
| §2 常量   | 状态枚举、表格列配置、按钮矩阵  |
| §3 页面   | 标注新建/改造，结构、字段、跳转 |
| §5 交互   | 展开 §0 点击表，状态机          |
| §6 校验   | 前端校验、Toast 原文            |
