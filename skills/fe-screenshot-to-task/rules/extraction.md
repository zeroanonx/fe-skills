# 截图内容提取

> Phase 1 读图 checklist。确认门禁与落盘流程见 [SKILL.md](../SKILL.md)。

## 产品五问（必答，写入 §0）

| # | 问题 | 提取要点 |
|---|------|---------|
| 1 | **做什么** | 产品目标、用户动作、解决什么问题 |
| 2 | **怎么做** | 页面/组件/交互如何实现 |
| 3 | **从哪里到哪里** | 入口菜单 → 中间页 → 终点 |
| 4 | **新建什么** | 逐页标注：新建 / 改造 / 复用 |
| 5 | **点什么出什么** | 每个关键按钮 → 跳转/弹窗/抽屉/提交/状态变更 |

## 业务线识别

从侧边栏菜单、产品 Logo、PRD 标题、用户说明推断；无法判断 → 列入待确认，不得留空。

## 点击操作

对每张截图每个可交互元素记录：

```text
{页面} → 点击「{元素}」→ {结果}
```

| 结果类型 | 示例 |
|---------|------|
| 页面跳转 | 列表 → 详情 |
| 弹窗/抽屉 | 点击「详情」→ 右侧抽屉 |
| 提交 | 确认 → 接口 → Toast → 刷新 |
| 状态变更 | 审核通过 → 状态更新 |

## 页面分类

| 类型 | 判断 | 任务标注 |
|------|------|---------|
| 新建页面 | 新菜单/路由，代码库无对应文件 | **新建** |
| 改造页面 | 已有页面增删区块/字段 | **改造** |
| 新建组件 | 弹窗/抽屉，无独立路由 | **新建组件** |
| 复用 | 与已有实现一致 | **复用** |

## 必提取项

- [ ] 页面标题、菜单路径、面包屑
- [ ] 筛选项、表格列、操作列及显示条件
- [ ] 表单字段、必填、条件显示
- [ ] 弹窗触发、确认/取消行为
- [ ] 状态枚举与流转（如有）
- [ ] 权限：菜单可见性、按钮级操作

## 前后端边界

| 写入任务 | 不写入（§8 范围外） |
|---------|-------------------|
| 页面、组件、路由、交互、校验、常量、权限 | 后端实现、API 定义、部署联调 |

## 自检（进入步骤 3 前）

- [ ] 五问已答，§0 素材充足
- [ ] 字段表、点击操作表完整
- [ ] 用户路径从入口到终点连通
- [ ] 无不理解项遗留（均已确认）
- [ ] 路由方案已向用户确认
