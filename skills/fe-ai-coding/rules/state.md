# 状态管理

局部 UI 状态留在组件/hooks/composables；跨页面共享或确需持久化时复用已有 store，按业务拆分，避免与具体 UI 组件耦合。

不强制 Zustand、Pinia 等特定库。持久化必须有需求依据，考虑过期、版本变化和退出清理；跨页面共享不等于需要刷新后保存。

## 生命周期与异步

查询/提交考虑 loading、empty、success、error 与防重复提交；快速切换条件避免旧响应覆盖新结果，采用项目已有取消或请求序号方案。计时器、监听、订阅和手动异步任务有停止/清理条件，hook/composable 副作用在注释中说明。错误责任见 [API](api.md)。
