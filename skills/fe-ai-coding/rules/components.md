# 组件与类型

- 页面负责编排；单页使用的子组件放在页面模块，多页面复用组件才进入既有公共组件目录
- 以职责、复用、状态复杂度决定拆分，不以固定行数强拆；已有组件小幅扩展可满足需求时保持兼容
- props/emits/slots/v-model 或回调保持现有命名与明确类型；不把整份页面状态无选择地传给子组件
- 交互优先使用项目组件库与二次封装，沿用表单、表格、分页、上传、弹窗模式
- 类型放入项目既有 types/interfaces 或局部模块，区分请求 Params/Body/Response 与展示模型；不强推固定文件名或 barrel 导出

## 组件契约检查

加载、禁用、空态与错误态沿用组件库能力；兼容扩展避免改变默认行为。子组件通过既有事件/回调更新父级，避免隐式修改传入状态。拆分后检查样式作用域、slot/children、透传属性和焦点/表单关系。
