# 语言与模板编码细则

沿用项目 Lint/Formatter 和现有语言版本，以下是缺少明确约定时的建议，不用于全库格式化。

- 变量/函数用英文语义名称或通用缩写；中文业务项目注释解释业务目的，代码名称保持英文。
- 不重赋值使用 const，需要重赋值使用 let；控制流优先清晰分支和早返回，复杂嵌套拆成有业务语义的函数。
- 字符串、分号、缩进和属性换行按项目配置；动态字符串使用可读模板字符串，不用反斜杠行尾续行。
- 优先字面量、明确参数与 rest；参数修改须遵从函数契约，避免隐式修改调用方共享对象。
- 数组/对象遍历根据实际语义选择，枚举对象时考虑自有属性；不能将普通 for 的性能假设推广到所有场景。
- 判断已声明变量是否 undefined 可直接比较；未声明名称才考虑 typeof，禁止复制错误的统一判断模板。
- HTML/Vue template 合法闭合、语义化、属性按项目引号约定；自定义元数据用 data-*，样式优先 class，功能所需 id 保留。
- 图片名称表达素材用途，倍图按项目 @2x/@3x 约定；必要时使用本地压缩流程，不自动向外部网站上传素材。

生命周期与异步处理见 [状态规则](state.md)，类型与外部数据见 [类型规则](types.md)。
