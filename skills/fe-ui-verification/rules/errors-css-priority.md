# CSS 层叠覆盖

**触发**：代码中已设置样式，但页面真实 display、尺寸或颜色不符。

1. 读取元素 computed style 与匹配规则，确认目标属性的赢家。
2. 查看来源、选择器权重、声明顺序、层叠层、important、内联及组件默认样式。
3. 确认父级影响属于继承、布局约束还是同元素 class 覆盖，不混为一谈。
4. 在真实冲突位置调整作用域、组件公开覆写接口或顺序，避免盲目追加更高权重。

CSS Modules 仅隔离类名；传入 className 与内部 class 同挂一元素仍会竞争。源码里后出现的规则也不一定胜出，需结合层叠条件。

复验目标组件所有受影响状态及其他使用方，报告具体生效规则和截图。
