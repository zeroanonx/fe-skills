# 设计侧取证

先核对用户指定版本、画板/节点和目标状态。使用当前可用 Figma/Pencil 工具，并遵守其工具说明与前置技能；不假设固定 API 名称和参数。

- Figma：保留链接、节点、版本或获取时间；取同一 frame 的截图和可读节点属性。
- Pencil .pen：保留文件路径、画板和节点 ID；取布局、截图，必要时查 fill、stroke、字体和 effect。
- 静态图：直接查看原图，记录像素尺寸与裁切范围；精确字体/间距无法读取时说明估算或未知。

先整体后局部，设计与实际页面使用一致区域、视口/比例、主题、数据和弹层状态。设计截图像素不自动等于 CSS 像素；来源比例不明时不能报告精确像素差。

只有分析清单而无法读取原始设计时说明基准限制，不能宣称已直接对照设计。工具不可用可用已有导出图，均不可用时记录受阻。

与 [浏览器取证](tools-browser-navigation.md) 配合，保存真实证据；只有工具内图片时保留可追溯引用，不伪造本地截图。
