# HTML 生成与打开

本技能交付 **report.html + report.md**，位于同一 run-id 目录。不得只生成其中一份或只在聊天中给摘要。

## 模板与内容

使用 [HTML 模板](../template/report.html) 保留标题、目录、各章节和 Markdown 链接。填写 {{title}}、{{run_id}}、{{subtitle}}、{{generated_at}}、{{report_ref}}（本次 report.html 完整绝对路径）及各 `*_html` 内容区。按同一份分析/验收数据生成两种格式，ID、数值、状态、限制与证据一致。

文本插入 HTML 前转义 `& < > "`，不能把设计文案当 HTML 执行。`*_html` 仅放生成的可信结构，内部文本和属性仍要转义；链接只使用已核实的本地相对路径或 http/https 来源，不把用户内容注入脚本或事件属性。报告无需 CDN、远程字体；模板自带的少量本地脚本只用于勾选、生成与复制修改指令，阅读报告无需 JS。

表格包在 `.table-wrap` 中；截图使用 figure/img/figcaption，设置有意义的 alt。图片链接指向真实截图，缺证据写限制而不是空图。设计/实际或前后截图可用 `.evidence` 并排，小屏自动堆叠。不适用章节写原因，有重复区域时增加子标题和稳定 ID。

## 修改意见复选项

`modifications_html` 填写全部意见，每项使用可访问 label 和唯一选择 ID。示例结构：

```html
<label class="selection-item">
  <input type="checkbox" name="modification" value="UI-001">
  <strong>UI-001 · P1 · 筛选区对齐</strong>
  <span>填写具体方案、期望效果、影响、依赖与验证方式。</span>
</label>
```

每个选择 ID 唯一，修改意见与 Markdown 保持一一对应。默认不添加 checked，页面重新加载也回到未选状态；需要跨轮次执行时使用用户已经发回对话的指令，不能靠浏览器暂存勾选推断。已选择项的用户决定另列记录，与 Markdown 同步；待决定的复选框不是执行授权。无修改意见时写“本次没有待选择的修改意见”，选择按钮保持禁用。

保留模板内生成/复制指令功能。勾选→生成→用户将指令发送到当前对话后，按 [选择流程](workflow-modification-selection.md) 执行；不得假称点击按钮即可后台启动 Agent。

## 生成后检查

- 所有模板变量已替换；标题、日期、目录、锚点和 report_ref 正确。
- 检查未选时按钮禁用、勾选生成只含所选 ID、改变选择会清空旧指令；生成指令包含报告路径与更新时间。
- HTML 与 Markdown 的内容一致，Markdown 链接及截图路径存在。
- 浏览器中检查长表格、图片、移动宽度和打印样式；不把打开文件的工具成功当成已检查渲染。

## 主动打开

生成并检查文件后，使用当前环境的文件预览/浏览器打开能力，**主动打开本次 report.html**。无内置能力时可使用系统默认应用，例如 macOS 的 `open <绝对路径>`；遵守环境权限，不为打开报告修改系统设置。浏览器不支持本地文件时，使用允许的本地静态服务预览同一份文件。

仅打开本次 run-id，不打开旧报告或模板代替结果。工具失败或没有打开能力时，在交付中说明尝试与限制，同时提供 HTML、Markdown 的完整绝对路径。用户明确要求不打开时遵从用户。
