# 验收与交付检查

## 验收前

- [ ] URL、设计版本、视口、主题与状态已定位。
- [ ] 实际页面与设计证据可读取，阻碍已明确。
- [ ] 分析清单如有已读取，缺少清单不阻塞直接比对。

## 验收中

- [ ] 浏览器真实打开页面并取证，字体/图片/数据状态已确认。
- [ ] 布局、层级、文字、图片均逐区核对，包含顶部、右侧与底部。
- [ ] 样式与指定交互/响应式状态已检查；未验证、不适用写原因。
- [ ] 差异按影响定级，附设计期望、实测、步骤与证据。

## 修改意见与选择

- [ ] 所有修改意见已展示，包含 P0/P1/P2、影响、依赖和验证方式。
- [ ] HTML 勾选项默认未选，Markdown 使用同一 ID。
- [ ] 有待执行意见时已询问并收到用户选择；无意见直接交付。
- [ ] 已确认所选 ID、报告版本、互斥方案和依赖；未回复时不改业务代码。
- [ ] 只修改所选项，未选择项保留未关闭状态。

## 修复后（有修复时）

- [ ] 用相同条件重新取证；只改代码的项仍为待复验。
- [ ] 状态与数量同步，旧证据保留。
- [ ] 有分析遗漏时记录 [反思](workflow-reflection.md)。

## 交付

- [ ] report.html 与 report.md 同轮次、内容和状态一致。
- [ ] 文件链接、截图、锚点、长表格和结论可读。
- [ ] 已主动打开本次 HTML；打不开则明确记录失败原因。
- [ ] 交付绝对路径、结论、未关闭问题与未验证范围。
