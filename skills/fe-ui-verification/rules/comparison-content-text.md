# 文字内容比对

从上到下、从左到右、从外到里核对指定范围。该维度必查，但问题等级按 [分级规则](comparison.md) 的实际影响决定。

- 按区域核对欢迎语、大标题、副标题、说明、按钮、链接、Tab、标签、占位和校验提示。
- 区分产品固定文案与动态样例数据；数据不同不能直接判错字，字段缺失需排查接口/权限状态。
- 检查字号、字重、行高、字距、颜色、换行和省略，先确认字体已加载。
- 顶部标题、右侧操作与折叠区不能漏；长文案及目标语言下复查截断和按钮撑开。
- 记录完整期望文案与实际文案、区域和截图；无法辨认的设计文案标待确认，不自行补字。

每项记录通过、存在差异、未验证或不适用；后两者写原因。差异用稳定 ID 关联设计与实际证据，不将未验证计为通过。
