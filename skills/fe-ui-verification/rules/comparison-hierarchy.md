# 视觉层级比对

从上到下、从左到右、从外到里核对指定范围。该维度必查，但问题等级按 [分级规则](comparison.md) 的实际影响决定。

- 从外到里确认背景、卡片、标题区、内容区、操作区的分组和边界。
- 核对父子/兄弟的视觉关系、页面阅读顺序，以及弹层、遮罩、下拉与固定头部的叠放。
- 关注遮挡导致不可点、裁切弹出层和滚动容器关系；有问题再查 stacking context、overflow、定位参照。
- 不强制 DOM 与 Figma/Pencil 图层一致，不因省掉无视觉影响的容器而报错。
- 记录被遮挡元素、触发状态、截图和真实计算样式；未经测量不推断 z-index 数值。

每项记录通过、存在差异、未验证或不适用；后两者写原因。差异用稳定 ID 关联设计与实际证据，不将未验证计为通过。
