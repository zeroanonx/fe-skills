# Grid 列数异常

**触发**：预期多列却只有一列，或轨道超出容器。

测量容器实际可用宽度 W、轨道最小宽 m、gap g。简单等宽条件下可容纳列数约为 floor((W + g) / (m + g))，仅用于诊断；最终以真实轨道和元素尺寸为准。

检查父级约束、shrink-to-fit、inline-grid、min-content 和模板轨道。普通块级 Grid 可自动获得可用宽度，无显式 width 不等于错误。

确认原因后修改父级分配、轨道最小值或内容溢出，不能只堆 `width: 100%`。验证窄屏、末行、长文本和空列表，参照 [列表规则](writing-list-layout.md)。
