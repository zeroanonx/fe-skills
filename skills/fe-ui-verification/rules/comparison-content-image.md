# 图片与图标比对

从上到下、从左到右、从外到里核对指定范围。该维度必查，但问题等级按 [分级规则](comparison.md) 的实际影响决定。

- 逐区检查图片、占位、图标是否存在且素材正确，记录资源来源和加载状态。
- 对比实际宽高、宽高比、裁切/object-fit、位置、圆角和与邻接元素间距。
- 多图拼接检查左右/上下/网格、数量及各图占比；不能只比外框忽略单图。
- 区分素材未提供、加载失败、权限拒绝与错误资源；占位布局通过不等于最终素材通过。
- 在数据和加载条件一致时取设计、实际截图；缺失资源记录影响与替换点。

每项记录通过、存在差异、未验证或不适用；后两者写原因。差异用稳定 ID 关联设计与实际证据，不将未验证计为通过。
