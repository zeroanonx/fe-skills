# 分析不足反思

有实际遗漏时，在本次报告末尾追加建议，无遗漏不强行凑反思。

| 问题来源 | 应追问 | 补充方式 |
| --- | --- | --- |
| 清单遗漏 | 顶部、右侧、底部、小元素或状态是否未记录 | 补区域 ID 和检查项 |
| 描述不清 | 尺寸单位、相对位置、样式来源是否缺失 | 补测量依据和设计期望 |
| 布局理解错误 | 是否未区分固定列、流式、限宽或滚动 | 补布局策略与断点证据 |
| 样式覆盖 | 是否忽略组件默认样式或主题 | 记录覆写来源 |
| 验证不足 | 是否未实际触发状态或查看目标视口 | 补复验条件和证据 |

建议格式：问题 ID → 原分析项 → 缺失原因 → 建议补充字段 → 证据。可按任务范围完善本次分析文档；修改共享 Skill 必须有用户明确要求，不自动写入安装目录。
