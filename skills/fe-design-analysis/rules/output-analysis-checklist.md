# UI 分析清单内容结构

HTML 与 Markdown 必须包含相同的业务内容，区域 ID、来源、待确认项保持一致。完整字段使用 [Markdown 模板](../template/analysis.md)，HTML 外观使用 [HTML 模板](../template/analysis.html)。

| 章节 | 需保留的细节 |
| --- | --- |
| 基准 | 时间、来源、节点、版本、画板尺寸、坐标和分析范围 |
| 整体布局 Map | 各状态、区域坐标/尺寸、父级、相邻区块间距 |
| 逐区分析 | 文字、图片、布局、层级及对应证据 |
| 样式汇总 | 颜色/透明度、字体、圆角、间距、阴影、模糊、token 映射 |
| 状态与响应式 | 已提供的交互/视口与缺失规格，不臆造 |
| 素材与实现建议 | 占位尺寸与替换点、组件划分、布局方案、风险 |
| 后续验收 | 检查 ID、区域/状态、期望、来源与验证方法 |
| 覆盖与待确认 | 首屏、右侧、底部、小元素检查结果，未读到的内容 |

估算值加约数与来源；未知写原因；比例与宽高须自洽。不能预先勾选尚未检查的项，也不能把模板示例当实际设计。
