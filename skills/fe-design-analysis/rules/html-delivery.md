# HTML 生成与打开

本技能交付 **analysis.html + analysis.md**，位于同一 run-id 目录。不得只生成其中一份或只在聊天中给摘要。

## 模板与内容

使用 [HTML 模板](../template/analysis.html) 保留标题、目录、各章节和 Markdown 链接。填写 {{title}}、{{run_id}}、{{subtitle}}、{{generated_at}} 及各 `*_html` 内容区。按同一份分析/验收数据生成两种格式，ID、数值、状态、限制与证据一致。

文本插入 HTML 前转义 `& < > "`，不能把设计文案当 HTML 执行。`*_html` 仅放生成的可信结构，内部文本和属性仍要转义；链接只使用已核实的本地相对路径或 http/https 来源，不注入脚本或事件属性。无需 CDN、远程字体或 JS 才能读报告。

表格包在 `.table-wrap` 中；截图使用 figure/img/figcaption，设置有意义的 alt。图片链接指向真实截图，缺证据写限制而不是空图。设计/实际或前后截图可用 `.evidence` 并排，小屏自动堆叠。不适用章节写原因，有重复区域时增加子标题和稳定 ID。

## 生成后检查

- 所有模板变量已替换；标题、日期、目录和锚点正确。
- HTML 与 Markdown 的内容一致，Markdown 链接及截图路径存在。
- 浏览器中检查长表格、图片、移动宽度和打印样式；不把打开文件的工具成功当成已检查渲染。

## 主动打开

生成并检查文件后，使用当前环境的文件预览/浏览器打开能力，**主动打开本次 analysis.html**。无内置能力时可使用系统默认应用，例如 macOS 的 `open <绝对路径>`；遵守环境权限，不为打开报告修改系统设置。浏览器不支持本地文件时，使用允许的本地静态服务预览同一份文件。

仅打开本次 run-id，不打开旧报告或模板代替结果。工具失败或没有打开能力时，在交付中说明尝试与限制，同时提供 HTML、Markdown 的完整绝对路径。用户明确要求不打开时遵从用户。
