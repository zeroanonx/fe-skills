# 常见实现错误与分析预防

| 现象 | 应查证的原因 | 分析中补充的规格 |
| --- | --- | --- |
| 内容区留白过大 | 限宽、侧栏、父级 padding 与设计不符 | 容器宽度策略和两侧距离 |
| Grid 仅一列 | 可用宽度、轨道最小值、gap 或父级约束 | 卡片尺寸、列数、断点证据 |
| Flex 不铺满 | grow/basis/最大宽与设计目标不符 | 是否拉伸、末行是否填充 |
| 换行后列宽不同 | Flex 逐行分配且设计要求跨行等宽 | 跨行列宽约束 |
| 文字与图标偏移 | 字体、行高、交叉轴、baseline | 对齐方式与字体规格 |
| 按钮位置/尺寸错误 | 盒模型、min-size、定位参照 | 外框尺寸、内边距、参照容器 |
| 样式失效 | 层叠顺序、权重、内联或组件默认样式 | 使用组件及覆写边界 |
| 元素裁切 | overflow、固定高度、长内容 | 长文案、滚动和省略策略 |

这些是诊断线索而非结论。先查证再建议修改；max-width、固定列、Flex、半露卡片都不能单凭属性判错。实际错误需由页面证据确认。

补充分析时将问题映射回区域 ID 和缺失字段；不要复制特定页面数值为通用规则。布局选择与合法示例见 [实现建议](implementation-guidelines.md)。
