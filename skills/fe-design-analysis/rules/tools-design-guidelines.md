# 设计来源与工具

先查看当前环境实际可用的工具及其说明；使用指定服务的工具时遵守该工具/技能的前置要求，不假设固定 MCP 名称、方法或参数。

| 来源 | 获取方式 | 应保留的证据 |
| --- | --- | --- |
| Figma | 使用可用 Figma 工具或可访问的设计页面，定位用户指定画板/节点 | 链接、节点 ID、版本/获取时间、截图及可读属性 |
| Pencil `.pen` | 使用支持该文件的设计工具，读取画板及节点 | 文件路径、画板/节点 ID、截图及布局信息 |
| 静态截图/标注 | 直接查看原图，必要时查看局部；保留原图比例 | 原图来源、像素尺寸、裁切区域、标注和估算区别 |

先看整体再读节点属性，避免把错误 frame 的样式当目标设计。多画板分别记录，不混用暗色/浅色或移动/桌面尺寸。

工具不可用或链接无权限时，不调用猜测的 API。已有导出图可先分析可见部分；否则请求用户提供可访问设计，记录受阻范围。可访问的截图不能证明隐藏的交互或精确样式属性。

截图确实保存后才在报告使用相对图片链接；仅有工具内图像时保留可追溯引用并说明未落盘。不要把分析结果写入技能包。
